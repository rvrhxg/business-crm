# Демонстрация Contour

Нужен Node.js 24. Используйте отдельную БД; скрипт отказывается менять базу с существующими пользователями. Все имена, клиенты и сделки вымышленные.

PowerShell:

```powershell
$env:DATABASE_PATH = 'contour.demo.sqlite'
Get-Content -Raw password-file | node src/demo.js
npm start
```

Файл password-file содержит придуманный пароль длиной 12–128 символов и хранится вне репозитория. Не используйте пароль от реального аккаунта. Откройте http://localhost:3001, аккаунт demo@example.test, пароль — переданный через stdin. Для возврата к обычной БД используйте новый терминал либо удалите переменную DATABASE_PATH из окружения.

Показ на 5 минут: объясните показатели активной воронки и выигранных сделок; откройте предложение, добавьте заметку и задачу, выполните задачу; переведите сделку в выигранные и покажите изменение истории и агрегатов. Создайте второго пользователя и покажите пустую клиентскую базу. Откройте HTTP-тест попытки доступа к чужому ID.

Объясните, что сумма API указана в копейках и проверяется сервером, а терминальные этапы нельзя открывать повторно. Отдельно назовите ограничения: нет общего командного пространства, уведомлений, восстановления пароля и полной пагинации. Это самостоятельный проект, а не коммерческий кейс.
