# Состояние приёмки CRM

| Область | Подтверждение |
|---|---|
| Деньги и этапы | Доменный тест: целые копейки, запрет отрицательных сумм, терминальные этапы, история |
| Изоляция владельцев | HTTP-тест: чужие клиенты/сделки/задачи недоступны |
| Рабочий API | HTTP-тест: клиент, сделка, этап, задача и агрегаты |
| Авторизация и ввод | Негативные тесты: JSON, размер, media type, CSP, истечение сессии, throttle |
| Интерфейс | Реализован; syntax check прошёл, Chromium ещё не запускался |
| DOM-инициализация | Автоматически проверены воронка и открытие карточки, пользовательский HTML выводится текстом |
| Редактирование контактов | Проверены успешное изменение и запрет изменения чужого клиента |
| Docker | Файлы есть; сборка и runtime не проверены |
| Скриншоты | Пока отсутствуют |
| Публикация | Ожидается отдельный репозиторий пользователя |

CI включает настоящий Chromium-сценарий и сохранение desktop/mobile снимков. Он должен пройти после публикации; наличие скрипта не означает успешную проверку. Для завершения нужно проверить CI, изучить реальные скриншоты и устранить найденные ошибки.
